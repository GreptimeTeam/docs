# 关于 GreptimeDB 版本号

GreptimeDB 遵循[语义化版本控制](https://semver.org/)，版本号格式为 `主版本号.次版本号.修订号`。例如，在 `1.2.3` 中：

- `1` 是主版本号。
- `2` 是次版本号。
- `3` 是修订号。

## 主版本号 (1)

发布版本包含不兼容的 API 或行为变更时，递增主版本号。升级到新的主版本可能需要调整客户端、配置或部署流程，因此迁移前应阅读对应版本的升级说明。

## 次版本号 (2)

发布版本以向后兼容的方式新增功能时，递增次版本号。次版本可以增加 SQL 功能、API、配置项或运维能力，同时保持已有公开接口兼容。

## 修订号 (3)

发布版本包含向后兼容的错误修复、安全修复或性能改进时，递增修订号。修订版本不会有意引入公开接口的不兼容变更。
